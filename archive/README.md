# archive/ — historical & superseded docs

These are **not sources of truth.** They're build-era audits, research, design notes, and
superseded planning docs, parked here on **2026-08-01** to declutter the repo. Kept (not
deleted) for provenance; moved with `git mv` so history is intact. Nothing here is
referenced by application code.

**For live status, use the docs still at the top level:**
- **`AUGUST.md`** — the v1.0 launch tracker (single source of truth)
- **`WAVE_TRACKER.md`** — the active punch-list (found-gaps + fixes)
- **`CLAUDE.md`** — project + design-system guide

Paths mirror where each doc used to live:
- `archive/root/` — old root planning docs (AUDIT, PLAN, the July step docs, session notes)
- `archive/audit/` — ~30 build-era audit reports (findings resolved / superseded)
- `archive/docs/` — old research, design-craft, and abandoned plan/handoff/guide folders

If you ever resume something in here, move it back out with `git mv` and add it to AUGUST.md.
