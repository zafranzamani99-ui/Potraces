Add Auto Log

Logs your Apple Pay taps automatically. Set up Quick Log (Back Tap) first — this reuses the same key.

Add the Shortcut

reuses your Quick Log key

For iPhone users who pay with Apple Pay. Optional.

§ 1 · Set it up

A bit more wiring, once.

  1. 1

    Add the shortcut

    Tap the button above, then in Safari tap the download → the file → 'Add Shortcut'.

  2. 2

    Create the automation

    Open Shortcuts → Automation → New → Transaction (or Wallet on iOS 26). Set 'Run Immediately' and turn notifications off.

  3. 3

    Feed it the payment

    Add a Text action that reads Amount, Merchant and Card (double-tap each to pick the field), joined with | like Amount|Merchant|Card. Then add 'Run Shortcut → Potraces Auto Log' with that text.

  4. 4

    Pay with Apple Pay

    Potraces logs it automatically as category 'Other' — just set the real category later in the app.

§ 2 · If it doesn't work

Common hiccups

Nothing logged after paying?

Apple's transaction trigger can be slow or miss a tap — it's an iOS limitation. Try another payment.

Amount is 0 or wrong?

Rebuild the Text action — each field must be picked with the double-tap gesture, not typed.

No key error?

Set up Quick Log (Back Tap) first — that's what saves the key Auto Log reuses.

Works only with Apple Pay contactless taps — not DuitNow QR, TnG or cash. Few Malaysian banks support Apple Pay.
